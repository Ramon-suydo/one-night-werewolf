# Optional original narrator recordings

Web Speech narrates the public director timeline by default. To use your own original recordings, add MP3 files here before building. The supported basenames are: dealing, doppel, wolf, minion, mason, seer, robber, troublemaker, drunk, insomniac, gap, dawn, day, minute, vote, result. Existing werewolves and masons recordings remain accepted as aliases.

Record the original captions in rules/nightWindows.ts and lib/narrator-cues.ts. Keep each recording inside its fixed window. No recording may name a player or reveal private information. Files are optional: missing files use Web Speech without requesting a nonexistent asset. Playback follows the server timeline, seeks after reconnects, ducks music and always leaves captions visible. No human voice chat or microphone access exists.
